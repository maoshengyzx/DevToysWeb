# DevToysWeb

A collection of 38 online developer utilities — a web-based toolbox inspired by [DevToys](https://github.com/DevToys-app/DevToys). All tools run entirely in the browser, no server-side processing.

🔗 **Live:** [devtoysweb.cn](https://devtoysweb.cn)

## Tools

| Category | Tools |
|---|---|
| **Converters** | Number Base, JSON ↔ YAML, JSON → TypeScript, Unit Converter, SQL → Entity Class, CSV ↔ JSON |
| **Encoders / Decoders** | HTML Encode/Decode, URL Encode/Decode, Base64, JWT Decoder |
| **Formatters** | JSON, JSON Diff, SQL, XML, HTML/CSS/JS |
| **Generators** | UUID, Lorem Ipsum, Hash (MD5/SHA), Password |
| **Text** | Case Converter, Regex Tester, Markdown Preview, Text Diff, Text Dedup, Word Count |
| **Media** | QR Code, Image Compressor, SVG Converter, ICO Generator, Image Editor |
| **Network** | API Request, HTTP Status Codes |
| **Web** | Website Speed Test, SEO Meta Analyzer, robots.txt Generator |
| **More** | Cron Parser, Color Converter, Timestamp Converter |

## Tech Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- React Router v7
- Lucide Icons
- Deployed on Cloudflare Pages

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Type-check + production build |
| `npm run lint` | Run ESLint |
| `npm run preview` | Preview production build |
